alcy

An experimental statically-typed programming language.

The project is in early development and not yet usable: the language, its standard library, and the compiler are still being designed. The compiler is written in C++20 and targets native code through LLVM and WebAssembly through a direct back end, which is what lets the playground compile and run programs in the browser.

Open the playground Read the guide

The guide describes the language as it exists today, and every example in it is compiled when the site is built.
